# 서버 시계

웹사이트 서버 시간을 `시:분:초.밀리초` 형식으로 보여줍니다. 예매는 직접 하고, 정확한 타이밍만 확인하는 용도입니다.

## 실행

Python 3만 있으면 됩니다. 추가로 설치할 건 없습니다.

```bash
python server_clock.py                          # 기본: NOL(인터파크) 티켓
python server_clock.py https://사이트주소        # 다른 사이트
python server_clock.py --cli                    # 창 없이 터미널에 표시
```

- 창은 항상 다른 창 위에 떠 있으니 예매 창 옆에 두면 됩니다.
- 오픈 1~2분 전에 **다시 측정**을 한 번 누르면 가장 정확합니다.
- `오차 ±Nms`는 측정 정확도입니다. 보통 수~수십 ms가 나옵니다.

## 원리

HTTP 응답의 `Date` 헤더는 초 단위까지만 알려줍니다. 요청을 반복해 보내면서 각 응답의 범위를 겹치면 오차를 ms 단위까지 좁힐 수 있습니다. 각 응답이 알려주는 범위는 `서버초 - 받은시각 < 오차 < 서버초 + 1 - 보낸시각`입니다. 요청은 서버 초가 바뀌는 순간 근처에 맞춰 보내서 범위를 빠르게 좁힙니다.
