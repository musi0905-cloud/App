# 빠진 에셋과 남은 제작 과제 (v0.16.0, 2026-10-13)

전체 목록(경로와 기대 SHA-256)은 `asset_registry.json`의 `missing` 255줄에 있습니다. v05 스프라이트는 시점별 묶음 27줄(1,296장)로 셉니다. 아래는 게임에 미치는 영향 순으로 정리한 것입니다. "받지 못함"은 이 세션이 파일을 실제로 손에 넣지 못했다는 뜻이며, 원본이 없다는 뜻은 아닙니다.

## 받지 못한 이유

- **ZIP 크기:** 98개 ZIP 중 83개가 3MB를 넘습니다(가장 큰 것은 수백 MB). Drive 연결 도구로 받을 수 있는 크기는 약 3MB까지입니다. 9.4MB ZIP은 받는 도중 연결이 끊겼습니다.
- **직접 내려받기 차단:** `drive.usercontent.google.com`으로 직접 내려받으려 하면 이 세션의 네트워크 프록시가 403으로 막습니다(한 번 시도, 재시도하지 않음).
- **풀어 둔 폴더가 비어 있음:** 인수인계 폴더의 "압축 해제본" 폴더들은 하위 폴더만 있는 빈 골격입니다(`압축해제_실행결과_20261013.md`에도 "재업로드 미완료").
- **손상 ZIP:** `01_캐릭터_이전업로드_불완전_사용금지.zip`은 지시대로 받지도 쓰지도 않았습니다.

받는 방법(사용자 확인 필요): 아래 넷 중 하나면 됩니다.

1. Drive를 동기화한 PC에서 Claude Code를 실행하고 `extract_404_archives.py`를 돌립니다.
2. 환경의 네트워크 허용 목록에 Drive 내려받기 호스트를 추가합니다.
3. 필요한 ZIP을 이 저장소의 GitHub 릴리스 자산으로 올립니다.
4. ZIP을 3MB 이하 조각으로 나눠 Drive에 올립니다.

프레임이 들어오면 `python3 scripts/import-v05-frames.py --source <풀어 둔 NPC 폴더 상위>`를 실행합니다. 해시를 확인하고 QA 뷰어용 아틀라스를 만듭니다.
