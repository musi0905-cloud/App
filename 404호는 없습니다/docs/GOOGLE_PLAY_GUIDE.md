# Google Play 출시 가이드 (처음부터)

기준일은 2026-09-30입니다. Play Console 화면과 정책은 자주 바뀌므로, 각 단계에서 화면의 안내를 우선합니다.

- 앱 ID: `com.musi0905.room404`
- 가격: 3,300원 (유료 앱)
- 계정: 개인 개발자 계정

역할을 **[직접]** 과 **[Claude]** 로 표시했습니다. 본인 인증, 결제, 계정 가입은 직접 하셔야 합니다.

전체 약 **3~4주**가 걸립니다.

## 1단계. 개발자 계정 만들기 [직접]

1. https://play.google.com/console/signup 에 접속해 게임을 관리할 Google 계정으로 로그인합니다.
2. 계정 유형은 **개인(Personal)** 을 고릅니다.
3. 등록비 **25달러**를 결제합니다(1회). 해외 결제가 되는 카드가 필요합니다.
4. **본인 인증**: 신분증과 주소, 연락처를 입력합니다. 여기 적은 이름이 인증 서류와 같아야 합니다.
5. **Android 기기 인증**: Android 휴대폰에 'Play Console' 앱을 설치하고 같은 계정으로 로그인합니다. 신규 계정에 필요한 절차입니다.
6. 개발자 이름(스토어에 표시되는 이름)을 정합니다. 예: `musi0905`

## 2단계. 판매자 프로필 · 정산 [직접]

유료 앱을 팔려면 필요합니다.

1. Play Console → **설정 → 결제 프로필**에서 판매자 계정을 만듭니다.
2. 정산 받을 은행 계좌와 세금 정보를 입력합니다.
3. 판매 수입은 소득 신고 대상입니다. 판매 규모가 커지면 사업자 등록이나 통신판매업 신고가 필요한지 세무 상담을 받는 것을 권합니다.

## 3단계. Android 앱 빌드 [Claude]

Mac이나 Android Studio가 없어도 GitHub Actions에서 빌드할 수 있습니다.

1. v0.6 코드에 Capacitor Android 플랫폼을 추가합니다(`com.musi0905.room404`, targetSdk 36).
2. Android 뒤로가기, 결과 공유, 저장 방식을 앱에 맞게 고칩니다(`STORE_RELEASE_PLAN.md` 2장).
3. GitHub Actions로 **서명된 AAB 파일**을 자동으로 만드는 작업을 추가합니다.
4. **업로드 키**(앱 서명용 파일)를 만듭니다. 이 키는 GitHub 저장소의 Secrets에만 넣고, 코드에는 절대 넣지 않습니다. **[직접]** Secrets 등록은 안내에 따라 해 주셔야 합니다.
   - Play 앱 서명을 사용하므로, 업로드 키를 잃어버려도 Google에 요청해 재설정할 수 있습니다.

## 4단계. Play Console에 앱 만들기 [직접, Claude가 답변 초안 제공]

1. **앱 만들기**를 누릅니다.
   - 앱 이름: `404호는 없습니다`
   - 기본 언어: 한국어
   - 앱 또는 게임: **게임**
   - 무료 또는 유료: **유료**
   - ⚠️ **유료 → 무료로는 바꿀 수 있지만, 무료 → 유료로는 바꿀 수 없습니다.** 처음부터 유료로 만들어야 합니다.
2. **앱 콘텐츠** 설문에 답합니다. 답변 초안은 Claude가 작성합니다.
   - 개인정보처리방침 URL (필수): 게임이 데이터를 모으지 않는다는 내용의 페이지. GitHub Pages로 무료 게시할 수 있습니다.
   - 광고: 없음
   - 앱 액세스: 로그인 없이 전체 이용 가능
   - 콘텐츠 등급(IARC 설문): 공포 표현 수준을 정확히 답합니다.
   - 타겟층: 어린이 대상 아님 (예: 16세 이상)
   - 데이터 보안: 수집·공유하는 데이터 없음 (기기 안에만 저장)
3. **가격**: 대한민국 3,300원으로 설정합니다. 다른 나라는 자동 환산하거나 한국만 판매하도록 고를 수 있습니다.

## 6단계. 비공개 테스트 (12명 × 14일) [직접]

신규 개인 계정은 정식 출시 전에 반드시 거쳐야 합니다.

1. Play Console → **테스트 → 비공개 테스트**에서 트랙을 만들고 AAB를 올립니다.
2. 테스터 이메일(Gmail) **12명 이상**을 등록합니다. 여유 있게 15명 정도를 권장합니다.
3. 테스터가 참여 링크로 **테스트 참여(opt-in)** 를 하고, 앱을 설치해 실제로 플레이해야 합니다.
4. 12명 이상이 **14일 동안 계속** 참여해야 합니다. 중간에 누가 빠져 12명 아래로 내려가면 다시 셉니다.

⚠️ **유료 앱의 비공개 테스트에서는 테스터도 결제해야 합니다.** 내부 테스트는 무료로 설치되지만, 12명·14일 조건은 비공개 테스트만 인정됩니다. 선택지는 다음과 같습니다. (결정 필요)
- (가) 테스터가 3,300원을 결제하고, 개발자가 Play Console 주문 관리에서 환불합니다. 환불 후에도 설치를 유지할 수 있는지는 확인이 필요합니다.
- (나) 테스터에게 비용을 따로 보전합니다.


### 테스터 12명을 구하기 어려울 때

- 기한은 없습니다. 12명이 모인 날부터 14일을 셉니다. 12명이 모이지 않으면 정식 출시를 **신청할 수 없을** 뿐, 계정이나 앱이 삭제되지는 않습니다.
- **(A) 테스터 교환 커뮤니티**: 개발자끼리 서로의 앱을 테스트해 주는 모임(예: Reddit r/AndroidClosedTesting, 국내 개발자 카페)입니다. 무료이지만 다른 사람의 앱도 14일 동안 설치해 둬야 합니다. 유료 앱이면 참여자 결제 문제 때문에 사람을 모으기가 더 어렵습니다.
- **(B) 유료 테스터 모집 서비스**: 비용을 내면 12명 이상을 모아 주는 서비스입니다. 2026년부터 Google이 실제 사용 여부를 확인하므로, 형식적인 참여는 거절될 위험이 있습니다.
- **(C) 조직(사업자) 계정으로 가입**: 조직 계정은 12명·14일 조건이 없습니다. 개인사업자도 가능하며, Google이 업종을 제한하지는 않습니다. 필요한 것은 다음과 같습니다.
  - 사업자 등록 (홈택스). 업종에 게임·소프트웨어 개발 공급업을 넣는 것을 권장합니다.
  - D-U-N-S 번호 (무료). 사업자등록증의 상호·주소와 **글자까지 일치**해야 합니다.
  - 조직 웹사이트, 조직 전화번호. 웹사이트는 GitHub Pages 등으로 간단히 만들 수 있습니다.
- **(D) 원스토어 병행**: 등록비가 없고 테스트 인원 조건도 없습니다. Play 준비와 별개로 먼저 판매를 시작할 수 있습니다.

### 국내 법적 절차 (계정 종류와 무관)

- **게임제작업 등록** (게임산업법 제25조): 영리 목적으로 게임을 만들어 제공하면 개인이든 사업자든 시·군·구청에 등록해야 합니다. 등록하지 않으면 처벌 대상입니다. 유료 판매이므로 해당됩니다. 정부24에서 신청합니다.
- **통신판매업 신고**: 앱 마켓 판매에도 필요한지는 규모에 따라 면제 여부가 달라집니다. 구청이나 세무 상담으로 확인합니다.
- 두 절차 모두 사업자 등록이 먼저 필요한 경우가 많습니다. 담당 기관에 확인합니다.

## 7단계. 정식 출시 [직접]

1. 14일이 지나면 대시보드에서 **프로덕션 액세스 신청**을 합니다. 테스트 소감 등 몇 가지 질문에 답합니다.
2. 승인되면 프로덕션 트랙에 출시합니다. 앱 심사는 보통 수일이 걸립니다.
