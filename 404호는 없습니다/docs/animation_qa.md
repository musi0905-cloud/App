## 4. NPC06 입장 끝·퇴장 시작 이음

| 기준 | 값 | 비고 |
|---|---|---|
| 리그 뿌리 깊이 | 입장 끝 z 2.333m → 퇴장 시작 z 1.800m, **0.533m** | `walk_clips.json` checks |
| 실루엣 가장 낮은 줄 → 깊이 | 1014 → 1164px(720 기준, 설계 225px), **0.437m** | 이전에 보고된 "0.44m"는 이 방식으로 잰 값과 같음 |
| 머리 폭(이미지 실측) | **+28.1%** | 리그 예측 +29.6%와 일치 |
| 화면 증거 | `frame_qa/NPC06_seam.jpg`, `room404/test-artifacts/qa-viewer-seq-NPC06-enter47.png`·`-exit0.png` | QA 뷰어 '입장→대기→퇴장' |

**원인: 원본 렌더 경로.**

- 패키지 `render.js` 50행은 인물마다 같은 경로 상수를 씁니다.
  - 정면: `z = 2.92 − p0`
  - 후면: `z = 1.8 + p0`
- 일반 리그는 47프레임 동안 약 1.0m를 걸어 정면 끝이 1.87~1.95m가 됩니다. 그래서 1.8m와 0.07~0.15m 차이입니다.
- 노인 리그(`walk_rig_elder_v04.json`, 0.34m/s)는 0.587m만 걸어 2.333m에서 멈춥니다. 후면이 고정값 1.8m에서 시작하므로 0.533m가 비어 있습니다.

**원인이 아닌 것:**

- 엔진 변환, 피벗, 우리 쪽 경로 데이터는 원인이 아닙니다. `build-walk-binding.py`는 render.js 식을 그대로 옮겼고, 측정은 원본 프레임에서 했습니다.

**수정 방법과 결과:**

- 엔진에서 인물을 옮기거나 키워 맞추는 것은 지시상 금지입니다. 숨기지 않았습니다.
- 대신 제작 요청 `NPC06-sequence-PATH_GAP`을 냈습니다. 내용은 "후면 경로 시작을 입장 끝에 맞추기: `rear z = (2.92 − root_x(47)·S) + p0`"입니다.
- 이 식으로 계산하면 퇴장은 z 2.333m에서 시작해 2.920m(입장 시작점)에서 끝납니다. 이음 차이는 0.000m가 됩니다.
- **실제 수정 후 측정값은 없습니다.** 원본 부품 그림(`assets/` 25개)이 없어 이 세션에서 다시 렌더할 수 없었습니다.
- 같은 식을 모든 인물에 쓰면 8명의 0.065~0.149m 차이도 없어집니다.

**코드 쪽 조치:** `stage.js`에 `clipUsable()`을 추가했습니다. 패키지가 PASS여도 아래 조건을 모두 만족해야 게임 무대에 클립을 올립니다.

- 프레임 검수에서 정면, 후면, 입장→대기→퇴장이 모두 PASS
- 이음 0.15m 이하

NPC06처럼 순간 이동하는 쌍은 표시가 잘못 바뀌어도 화면에 나오지 않습니다(`tests/stage.test.mjs`).

## 7. 게임 적용 (작업 지시 [4])

- **적용한 클립: 0개.** PASS인 인물·방향·동작이 없습니다.
- 게임은 그대로입니다.
  - 인터폰 BG02에는 레거시 방문객 그림과 승인 인물(CH09·CH10·MC15·MC25)이 정지 대기로 섭니다.
  - 들어오고 나갈 때는 제자리에서 불투명도만 0.25초 동안 바뀝니다.
- NPC별로 정지 대기를 유지하는 이유는 `walk_clips.json`의 `npcs.<id>.review`에 기록했습니다. QA 뷰어 상태 표에도 나옵니다.
- 지켜진 규칙:
  - 루트 이동 클립을 반복 재생하지 않습니다.
  - 구워진 이동 위에 엔진 이동이나 확대를 덧붙이지 않습니다.
  - 퇴장을 역재생으로 만들지 않습니다.
  - 배경, 인물, 그림자, 앞 가림, UI는 따로 그립니다.
  - 게임은 `walk_clips.json`을 읽지 않습니다(`tests/sw.test.mjs`, `stage.test.mjs`).

## 9. QA 뷰어 (`npm run qa` → `/room404/qa/`)

- **인물 레이어:** 기본값이 '스프라이트 프레임(원본 반입)'입니다. 원본 720x1280에서 만든 아틀라스(알파 상자 + 오프셋, 0.5배)를 고정 캔버스에 그립니다. 리그 골격이나 검토 MP4로 바꿀 수 있습니다.
- **방향:**
  - 정면·측면·후면 외에 '입장→대기→퇴장'을 추가했습니다.
  - 정면 0–47, 정면 47 정지 1초(대기 그림 없음), 후면 0–47 순서로 재생해 이음을 그대로 보여 줍니다.
  - 끝 프레임에서 멈추고 처음으로 돌아가지 않습니다.
- **상태 표:**
  - 방향별 프레임 검수 판정과 이슈 ID
  - 실측 이음(가장 낮은 줄, 깊이, 머리 폭)
  - 리그 미끄럼
  - 남은 문제
- **브라우저 테스트:** `tests/qa-ui.mjs` 8개(스프라이트 레이어 픽셀 확인, NPC06 연속 재생 포함)
- **정지 인물 합성 탭:** v0.16과 같습니다. 게임의 `stage.js`로 승인 인물·레거시 방문객을 세웁니다.
