## 2. 바인딩 계산 검증 (검토 영상 위에 겹쳐 보기)

`build-walk-binding.py`는 패키지 `render.js`의 투영식과 그림자식을 그대로 옮겼습니다. 이 계산으로 프레임마다 다음 세 가지를 만듭니다.

- 발 아래 바닥점
- 몸 상자(클릭 영역)
- 두 발의 접지 그림자 타원

같은 프레임의 검토 영상 위에 겹쳐 보았습니다(NPC03 정면 0·24·47, 측면 24, 후면 0·47 / 측면 0~20 4프레임 간격 / NPC03·NPC09 정면 24). 결과는 다음과 같습니다.

- 그림자 타원 중심이 영상 속 그림자·신발 위치와 겹칩니다.
- 몸 상자가 인물을 감쌉니다.
- 바닥점이 두 발 사이에 놓입니다.

QA 뷰어의 'MP4 검토 영상' 레이어에서 언제든 다시 볼 수 있습니다. 자동 테스트 `tests/qa-ui.mjs`가 화면도 남깁니다(`test-artifacts/qa-viewer-mp4-*.png`).

## 5. QA 뷰어 사용법

`room404/qa/`에 있습니다. 배포 폴더 `dist/` 밖이라 게임에는 들어가지 않습니다. 실행은 `npm run qa`로 하고, 출력된 주소의 `/room404/qa/`를 엽니다.

- **걷기 클립 탭**
  - 인물 9명 가운데 하나를 고르고 3방향(정면·입장 / 측면·지나감 / 후면·퇴장)을 바꿔 봅니다.
  - 재생은 한 번만 하고 47번에서 멈춥니다. '반복(검수용)'을 켜야 처음으로 돌아갑니다.
  - 멈춤, ◀1·1▶ 한 프레임 이동, 슬라이더, 방향키·스페이스를 쓸 수 있습니다.
  - 겹쳐 보기: 발 기준점과 이동 궤적, 바닥선·수평선·바닥, 접지 그림자, 클릭 영역, 가림, 인터폰 카메라 틀
  - 배경을 바꿀 수 있습니다. BG02 밖에서는 '클립은 BG02 카메라 기준' 경고가 나옵니다.
  - 인물 레이어는 리그 골격, 검토 영상(NPC03·09), 스프라이트 프레임(반입 후) 중에서 고릅니다.
  - 상태 표는 QA 판정, 기술 출력, 프레임 반입 수, 이음, 미끄럼, 남은 문제를 보여 줍니다.
- **정지 인물 합성 탭**
  - 게임과 같은 `stage.js`로 승인 인물이나 레거시 방문객을 BG02(인터폰·전체), BG12(카운터 가림)에 세웁니다.
  - 입장·퇴장·처음으로 버튼과 겹쳐 보기가 있습니다.
