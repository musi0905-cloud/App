### 발견한 품질 문제 (v1.1 데이터 자체)
- `visitors_100_complete.json`의 대사는 템플릿입니다. `arrival`은 96명이 같은 틀("저는 {이름}입니다. {호수}호에 볼일이 있어요. {사유}. 지금 확인해 주시겠어요?"), `when_asked`·`after_delay`·`on_allow`·`on_deny`는 **허용/거부 50:50으로 두 문장**이라 판정 전에 보여 주면 정답이 새어 나갑니다. 그래서 판정 **후** 반응 한 줄(`on_allow`/`on_deny`)만 씁니다.
- `endings_30_cutscenes.json`의 `ending_text` 본문은 30개 중 2종뿐(제목만 다름)이라 쓰지 않고, 엔딩마다 다른 컷신 자막 4개와 대사 3줄을 씁니다.
- `story_scenes_40.json` N1_08의 `actor`가 "배달 동승인"으로 적혀 있는데 실제 방문객은 V080 서지훈(차량 동승)입니다. 대사 자체는 그 자리에 맞아 그대로 씁니다.
- 같은 이름이 역할만 다르게 5번씩 반복됩니다(예: 김서윤 V001·V021·V041·V061·V081). 기획 08번 문서의 "개체 ID 분리" 지적과 같은 문제이며 데이터는 손대지 않았습니다.

- **에셋**: 블록아웃 SVG·역할별 보행 SVG는 기획 문서 스스로 "게임에 자동 적용 금지, 프로토타입"이라 해서 게임에 넣지 않았습니다. 실제 배경 13종·인물·증거 이미지·음향은 미제작(TODO).
