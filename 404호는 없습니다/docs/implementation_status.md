## 2. 게임 흐름 (작업 지시 10항)

- **N1과 E01~E06:** 기존 엔진 판정을 그대로 둡니다.
- **N2~N5:** v1.2 슬롯 40개(v0.14부터)를 씁니다.
- **긴급 신고와 출입 판단:** 서로 다른 버튼이고 다른 기록입니다.
- **기록 인물과 방문객:** 기록 인물(story_contact)과 방문객(gate visitor)은 다른 사람이고 다른 화면에 나옵니다.
- **증거 얻기:** 판정 → 독립 자료 대조로 입수합니다. 놓친 자료는 보관함에서 복구합니다.
- **입수와 확인:** 발견(입수)과 확인(교차 확인)은 다른 상태입니다.
- **본문:** JSON 텍스트를 확대 뷰어로 보여 줍니다.
- **정답 유출 없음:**
  - 판정 화면에 기록 내용과 증거 번호가 나오지 않습니다(story-ui 테스트).
  - 증거 본문에 살해 사실이 없습니다(world 테스트).
  - 2004년 배경은 2004년 기록에만 씁니다.
- **퍼즐:** 기록 대조 퍼즐 5개(PZ01~PZ05)가 있습니다.
- **엔딩:** v1.3 엔딩 30개 조건을 씁니다. 보관함 결말을 확정한 직후 `archiveEndingConfirmed`를 리셋합니다.

## 4. 실행 방법

```bash
cd "404호는 없습니다/room404"
npm ci
npm test && npm run test:ui && npm run test:all-cases
npm run qa        # 로컬 서버: <주소>/room404/dist/ = 게임, <주소>/room404/qa/ = 내부 QA 뷰어
npm run screens   # 폰·데스크톱 화면 캡처 → test-artifacts/screens
```

에셋을 다시 만들 때는 다음 순서로 실행합니다. 모두 해시가 맞지 않으면 멈춥니다.

```bash
python3 scripts/build-stage-assets.py     # 배경·인물 게임판, character_assets.json
python3 scripts/build-walk-binding.py     # walk_clips.json (v05 재현 코드 → 프레임별 데이터)
```

## 5. 끝내지 못한 것

1. **v05 걷기 스프라이트 1,296장과 부품 25개, 역할 그림 9장, CH06·CH08, BG 3장:** 이 세션에서 받지 못했습니다. 접근 방법만 정해지면 이어서 할 수 있습니다(`docs/missing_assets.md`).
2. **걷기 애니메이션 게임 적용:** 패키지 판정이 REVISE라 하지 않았습니다. PASS 판정과 프레임이 오면 `clipActor()`가 게임 무대에 연결합니다. 대기 자세 원화와 NPC06 이음 수정도 필요합니다.
3. **배경 좌표:** BG02 밖의 배경 좌표(수평선·바닥선 등)는 시각 추정값입니다. 인물을 세우기 전에 검수가 필요합니다.
4. **기획 결정 필요:** `docs/planning_conflicts.md`의 [기획 필요] 항목입니다. E03~E05 종료 여부, 장면과 결말의 연결, 관리소장 이름, EV15 날짜 등이 있습니다.
5. **실기기 테스트:** 하지 않았습니다(SKIP).
