## 받은 뒤 확인할 것 (스스로 점검)

1. **글자가 들어가 있지 않은가?** 표지판, 모니터, 옷에 글자가 생기면 다시 요청하세요. ("글자를 모두 지워 줘")
2. **인물이 참고 인물과 같은 사람인가?** 머리 모양, 옷 색, 신발이 다르면 "첨부한 인물과 옷과 머리를 완전히 똑같이" 다시 요청하세요.
3. **8장면의 크기와 발 위치가 같은가?** 칸마다 사람이 커졌다 작아지면 다시 요청하세요.
4. **배경이 1536×1024 가로인가?** 세로 그림이나 정사각형이면 다시 요청하세요.
5. **투명 배경인가?** 인물·소품에 흰 배경이나 회색 배경이 있으면 "배경을 투명하게" 다시 요청하세요.

## 게임에 넣는 방법

받은 파일을 Drive의 `404호는 없습니다_게임 개발` 폴더 안에 새 폴더 `이미지_v3`를 만들어 올리고 알려 주세요.
- 배경은 `backgrounds/`, 인물은 `visitor-0N/`(번호별), 소품은 `props/`, 화면용은 `screens/`에 넣어 주시면 됩니다.
- 파일 이름은 위 표의 이름을 그대로 쓰면 제가 바로 연결할 수 있습니다.
