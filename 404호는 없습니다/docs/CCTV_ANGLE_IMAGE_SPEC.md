# CCTV 여러 각도 보기 — 필요한 그림 규격

CCTV 화면에서 같은 순간을 여러 카메라로 바꿔 볼 수 있게 하려면 아래 그림이 필요합니다. 이 규격에 맞춰 만들어 주시면 바로 게임에 넣을 수 있습니다.

## 1. 배경 그림 (필수)

게임에 나오는 장소는 7곳입니다. 지금은 장소마다 한 방향 그림만 있습니다.

| 장소 (코드 이름) | 지금 있는 그림 | 새로 필요한 각도 |
|---|---|---|
| 공동현관 (`lobby`) | 정면 (`cctv-lobby.png`) | ② 옆에서 본 모습, ③ 천장에서 내려다본 모습 |
| 안쪽 복도 (`hall`) | 정면 (`apartment-scenes.png` 가운데 칸) | ②, ③ |
| 엘리베이터 (`elevator`) | 정면 (같은 파일 왼쪽 칸) | ② 엘리베이터 안 카메라, ③ 엘리베이터 앞 복도 |
| 계단 (`stairs`) | 정면 (같은 파일 오른쪽 칸) | ② 아래층에서 올려다본 모습, ③ 위층에서 내려다본 모습 |
| 주차장 (`parking`) | 정면 (`detail-scenes.png` 왼쪽 칸) | ②, ③ |
| 집 현관문 (`door`) | 문 열림/닫힘 (`detail-scenes.png`) | ② 복도 끝에서 문을 본 모습 |
| 현관 옆 카메라 (`lobbySide`) | 정면 그림을 잘라 씀 | 공동현관 ②를 쓰면 됩니다 |

**모든 배경 그림 공통**
- 크기: **1536×1024 픽셀(가로:세로 = 3:2)**, PNG
- **사람이 없는 빈 장소**로 그려 주세요. 인물은 게임이 따로 그립니다.
- 지금 그림과 같은 톤: 밤, 어두운 아파트, 흑백에 가까운 초록빛 CCTV 느낌
- **글자, 날짜, 시간을 넣지 마세요.** 게임이 화면 위에 표시합니다.
- 같은 장소는 다른 각도에서도 벽, 문, 조명 위치가 서로 맞아야 합니다. 그래야 "같은 곳을 다른 카메라로 본다"는 느낌이 납니다.
- 사람이 서 있을 **바닥 높이**를 알려 주시면 좋습니다. 예: "바닥은 그림 아래에서 10% 위치". 모르셔도 제가 그림을 보고 맞춥니다.

**파일 이름 예시**: `lobby-side.png`, `lobby-top.png`, `hall-side.png`, `hall-top.png` …

## 2. 인물 그림 (있으면 더 좋음)

옆이나 위에서 본 카메라에는 사람도 그 방향에서 본 모습이어야 자연스럽습니다.

- 지금 있는 것: 방문객 4명의 정면 그림, V001의 옆으로 걷는 8장면
- 있으면 좋은 것: 4명 각각의 **옆모습 걷기**와 **뒷모습** (V001과 같은 규격: 한 장면 384×512, 가로 4 × 세로 2, 투명 배경 PNG)
- 인물 그림이 없으면 옆 각도에서는 지금 그림을 좌우로 뒤집거나 작게 그려서 대신합니다.

## 3. 게임에서 쓰는 방법 (계획)

- CCTV 화면에 **카메라 버튼(① 정면 ② 옆 ③ 위)** 을 추가합니다. 누르면 같은 시각을 다른 각도로 보여 줍니다. 재생 위치는 그대로 유지됩니다.
- 그림 없이도 가능한 **"가까이 보기(확대)"** 를 함께 넣습니다.
- 사건마다 "다른 각도에서만 보이는 단서"를 넣을 수 있습니다. 예: 정면에서는 두 사람처럼 보이지만 위에서 보면 한 사람. 이 부분은 그림을 받은 뒤 사건별로 정합니다.
