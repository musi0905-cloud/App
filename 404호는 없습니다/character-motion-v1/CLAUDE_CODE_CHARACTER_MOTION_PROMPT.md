# Claude Code 적용 지시 — V001 걷기 모션

현재 프로젝트 `404호는 없습니다`에 이 폴더의 캐릭터 스프라이트를 적용하세요. 먼저 현재 코드와 `SPRITE_MANIFEST.json`을 읽고 실제 구조를 확인한 뒤, 아래 범위로 수정하고 검사 결과와 수정 파일을 Google Drive 프로젝트 폴더에 저장하세요.

## 코드 연결 위치

- 재현 장면 그리기: `dist/replay.js`의 `mountReplay`, 이미지 `ready` 목록, `actor()` 함수
- 방문객 얼굴 그림: `dist/game.js`의 `person()`; 이 작업에서는 portrait/ID 연결을 바꾸지 마세요.
- 조사 화면/재생 동작 회귀: `tests/browser.mjs`, `tests/all-cases.mjs`
- 오프라인 자원 버전: `dist/sw.js`

현재 CCTV actor는 `dist/assets/visitors.png`의 4개 가로 스프라이트 중 `(Number(visitor.id.slice(1))-1)%4`로 인물을 고릅니다. 새 그림은 기존 V001의 회색 코트 여성과 옷차림을 맞춘 별도 걷기 시트입니다. 생성 캐릭터 얼굴은 기존 초상과 완전히 동일하지 않습니다. 우선 V001에서만, CCTV 장면 중 걷기 동작(`s.action`이 `enter`, `cross`, `descend`)일 때 시험 적용하세요. 다른 방문객, 초상, 등록사진/얼굴 확대/서류 그림에는 적용하지 마세요. 얼굴 일치 판정, 사건 정답, 사건 자료는 그대로 유지하세요.

## 스프라이트 규격

- `visitor-v001-walk-8f.png`: 투명 RGBA, 1536×1024, 4열×2행.
- 한 프레임은 384×512. 프레임 순서: 위 행 왼쪽부터 1–4, 아래 행 왼쪽부터 5–8.
- 권장 재생 속도 8 fps, 순환 재생.
- `frames/walk-01.png` … `walk-08.png`는 프레임별 분리본이며 각 384×512.
- `walk-cycle-preview.gif`와 `walk-cycle-preview.png`는 빠른 검토용이며 게임 런타임 자산은 PNG 시트를 사용하세요.

## 동작 요구

1. 시트를 앱 정적 리소스(예: `dist/assets/visitor-v001-walk-8f.png`)에 복사하고 경로를 코드에 연결하세요. 다운로드 후 PNG의 alpha와 크기를 유지하세요.
2. `actor()`에서 V001의 이동 장면만 걷기 시트 프레임을 사용하세요. 각 프레임 소스 사각형은 `(frame % 4)*384`, `floor(frame/4)*512`, `384`, `512`입니다.
3. 프레임 번호를 실제 시간에 의존시키지 말고 재생 커서 `cursor`에 연결하세요. 예를 들면 `Math.floor(cursor * 8) % 8`로 계산하면 일시정지·구간 이동·재생이 같은 시점을 가리킵니다. 다만 선택한 장면의 시간 기준이 기존 재생 UX와 어긋나지 않도록 실제 코드에 맞춰 조정하세요.
4. 기존의 무빙 좌표, 사건별 카메라 모드, 색 필터, 소품, 그림자, CCTV 날짜·시간, 자막은 보존하세요. V001 아닌 인물의 기존 그리기는 바뀌지 않아야 합니다.
5. 프레임마다 투명 여백이 달라 보일 수 있으므로, 기준점(바닥/발 위치)을 화면에서 고정해 걷는 동안 인물이 위아래로 튀지 않는지 확인하세요. 필요하면 프레임 렌더 크롭/앵커 보정을 하되 원본 프레임은 덮어쓰지 마세요.
6. PWA 캐시가 새 이미지를 포함하도록 `dist/sw.js` 캐시 버전을 올리고, 구버전 캐시가 새 화면을 막지 않는지 확인하세요.
7. 화면을 직접 확인하세요. 생성 인물의 얼굴·옷이 방문객 카드와 완전히 같은 인물로 보인다고 단정하지 마세요. 이질감이 있으면 CCTV에만 제한하거나 정적인 기존 캐릭터를 유지하고 그 사유를 기록하세요.
