# 《404호는 없습니다》 손·소품 경계 수정 v05

2026-10-13. NPC02–NPC10의 v04 저장본을 복구해 이어서 수정했다. v04는 보존했으며 v05 검토본을 별도로 작성했다.

## 실제 변경

- NPC03(택배): 기존의 팔 부품과 소포에 붙어 있던 팔을 중복해서 그리지 않도록, 어깨부터 굽힌 팔·손·소포가 연결된 새 투명 원화로 교체했다. 기존 손에 비해 크기를 줄이고 소매 폭을 조정했다.
- NPC09(공공 업무): 같은 방식으로 어깨·팔·작은 손·서류철을 연결한 새 원화로 교체했다. 손목과 소품이 각각 떠 보이던 구조를 제거했다.
- 두 인물의 새 부품은 정면·측면·후면 3종이다. 소품을 든 왼팔은 어깨를 따라가는 고정 굽힘 포즈이고, 별도의 팔꿈치·손목 관절로 유연하게 변형하는 모션은 아니다. 반대팔과 다리는 보행 리그로 구동된다.
- 9명 공통: 허벅지·종아리 원화 상단의 딱딱한 절단선을 줄이도록 런타임에서 겹침 투명도를 조정했다. 바지 원본을 다시 그린 것은 아니다.
- 얼굴과 배경 소스, v04 발 궤적 및 리그는 유지했다. NPC02·04·05·06·07·08·10의 팔·소품 원화는 변경하지 않았다.

## 검수 범위와 남은 문제

9명 모두 3방향 첫 프레임 전후 비교와 측면 8구간을 확인했다. 새 원화를 넣은 NPC03·09는 정면·후면 8구간도 추가 확인했다. 전 프레임의 완전한 시각 검수 또는 엔진 내 재생 검수를 했다고 주장하지 않는다.

소매·몸통의 질감 차이, 남은 부품 경계, 제한적인 몸통 회전, 소품을 든 팔의 미세한 움직임은 추가 모션 제작 대상으로 남는다. 바지 경계는 완화했지만 완전히 연속된 옷감 변형은 아니다. 그림자와 조명은 v04 합성을 유지했으며 모든 게임 장면에서 검증되지 않았다.

이번 원화는 내장 이미지 생성 도구로 제작했다. 정확한 사용 프롬프트는 공통 코드 패키지의 prompts_v05.json에 있다. 기존 얼굴·헤어스타일을 재생성하지 않았다.

## 파일 사용

각 NPC ZIP의 README_v05.md, QA_v05.json, config.json, binding.json을 먼저 읽는다. 실제 참조되는 리그 파일을 함께 포함했다. NPC03·09는 carrying_binding_v05.json의 부품 좌표와 어깨 기준점을 사용한다. 후면 부품은 몸통 안쪽으로 소품이 들어가도록 부품에 한해 좌우 매핑했다.

sprites는 720×1280 RGBA PNG, MP4는 불투명 배경 합성 검토 영상이다. 배경합성 전체 PNG는 소스 코드로 재출력하며 ZIP에는 방향별 첫 프레임과 영상이 들어 있다. Node.js, @napi-rs/canvas, Python, ffmpeg/ffprobe가 필요하다.

이 파일들은 07_검수완료에 배포하지 않는다. 주요 시대별 인물과 사건 접촉 인물의 미제작 모션, 각 인물의 전체13종 포즈는 이번 출력 수량에 포함되지 않는다.
