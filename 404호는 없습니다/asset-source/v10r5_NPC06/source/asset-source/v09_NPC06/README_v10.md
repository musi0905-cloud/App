## 변경 범위
- 무릎 중심 영역에 기존 생성 원화를 연속 혼합. 바지 상단과 밑단, 원본 알파 유지.
- 후면 주름 혼합 강도를 정면보다 낮춤.
- 소매 질감과 색 보정. 손과 손목, 원본 소매 알파 유지.
- 몸통은 원본 옷깃·단추·중앙 셔츠를 보존하고 옆면만 제한적으로 혼합.
- 가방끈 신규 곡선과 밑단 연장 실험은 효과가 입증되지 않아 제외.
- 관절·경로·접지·그림자 데이터를 변경하지 않음. 게임에 연결하지 않음.

## 열려 있는 항목
정면/후면 다리 볼륨, 정면/후면 몸통 회전, 소매 전체 동작 검수, 후면 회전 가방끈. 기존 6개 요청은 자동 종결하지 않는다.
