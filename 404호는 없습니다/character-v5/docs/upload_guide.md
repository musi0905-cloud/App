# 《404호는 없습니다》 제작 결과 백업 안내

이 백업은 2026-10-08까지 확인된 제작 중간 결과물입니다. 폴더 이름의 '최종'은 모든 에셋의 제작·게임 적용 완료를 뜻하지 않습니다.

## 파일 구성

- 00_스타일가이드: 제작 기준, 인벤토리, 에셋 목록과 정지 배치 검수 자료.
- 01_캐릭터: 원본 및 게임용 정지 이미지. `01_캐릭터_복구완료_v02_part01~05.zip`을 사용합니다.
- 02_배경: 원본 및 게임용 배경. part01~03에 나뉘어 있습니다.
- 03_사건장면: 사건·방문객·엔딩 매핑과 대화 화면 정지 미리보기.
- 04_증거소품: 증거 이미지, 문서 렌더링, 텍스트 및 데이터.
- 05_UI: UI 이미지, 소스 및 한국어 텍스트.
- 06_애니메이션: 모션 제작·검수 명세. 완성 보행 애니메이션은 포함하지 않습니다.
- 07_검수완료: 기존 체크포인트의 정지 에셋 PASS 목록. 게임 엔진 및 보행 검수와는 별개입니다.
- 08_수정필요: 수정본·보류본과 검수 기록.
- 최상위 `생성원본_전체...part01~10.zip`: 기존 생성 원본 PNG 137장.
- 최상위 `제작작업_재개자료...zip`: 제작 스크립트, 기획 원문, 체크포인트.
- 01_캐릭터의 `MC01_MC04_추가생성_검수전...zip`: 이번 재개 작업에서 생성된 캐릭터 4장과 제작 명세. 합성 및 일관성 검수 전입니다.

각 part ZIP은 독립적으로 열 수 있는 일반 ZIP입니다. 분할압축 결합 프로그램 없이 같은 폴더에 각각 압축을 풀면 폴더 구조가 합쳐집니다.

## 검수 범위와 주의할 파일

기존 체크포인트에는 정지 에셋 58건(PASS 56건, REVISE 2건)이 기록돼 있습니다. 원본·게임용·수정 전후·미리보기·문서가 함께 저장되어 있으므로 전체 파일 수는 최종 합격 에셋 수와 다릅니다.

`01_캐릭터_이전업로드_불완전_사용금지.zip`은 과거 불완전 업로드를 표시한 파일입니다. 사용하지 말고 `복구완료_v02` 파일을 사용하세요.

기존 일부 게임용 이미지의 저장 손상을 원본에서 복구했습니다. 재개본의 이미지 파일을 읽기 검사했고, 업로드용 ZIP은 압축 내부 CRC 검사를 통과한 파일만 사용했습니다. 업로드 후 Drive 파일 크기를 로컬 원본과 대조합니다.

게임 엔진 적용 및 연속 보행 애니메이션 검수는 완료되지 않았습니다. 생성 원본과 DRAFT 파일을 곧바로 출시용 에셋으로 취급하지 마세요.
