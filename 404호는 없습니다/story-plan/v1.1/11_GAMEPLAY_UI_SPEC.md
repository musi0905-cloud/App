# 화면별 기능 명세 v1.0
## 홈
버튼 `첫 근무`, `이어하기`, `사건 기록`, `접근성`, `설정`; 이어하기는 save compatible 경우만 활성. 타이틀에는 범죄 진상을 숨긴다.
## 출입 판단 화면
현관 방문객·시각·현재 야간/슬롯·[CCTV 보기][주민·방문기록][집에 전화하기][한 번 더 확인][문 열기][문 열지 않기][긴급 신고] 필요. 인물 터치가 유일 정보 진입점이 되어서는 안 됨.
## CCTV
CAM-A/B, 시계 보정 표시, 18초 재현(6초×3), 정지/스크러빙/느린재생, 영상 한 컷에 보여 주는 텍스트 단서 메타 포함. 자동판정 금지.
## 기록
현행 원본/옛 사본/관리소 공지 '검증 등급' 각각 표시, 원본 발행일/출처/현재 확인 여부 병기. 열람=증거 획득 아님; `원본 비교` 동작 후 플래그.
## 통화
발신번호를 믿지 말고 등록 연락처로 걸기. 응답 기록에 `직접확인/대리확인/미확인` 구분. 통화 중 실제 긴급 신고는 별도 경로.
## 증거보드
사실/추정/반증 3 탭; 시각·출처 표기. 증거 연결은 PZ01~05 중 현재 공개된 명제에만 허용. 플레이어가 이름만 눌러 정답을 보는 치트 방지.
## 피드백
입장 판단과 진상 발견을 분리; 현재 확인 가능한 근거만 피드백. N5 이전 강태준 살해 사실 공개 금지.
## 종료/엔딩
사건별 오판, 필수 증거 보존, 피해자 명예·개인정보 선택 및 결말 조건 명시. 스포일러 없는 리플레이 메뉴.
## 접근성
탭 히트 영역 44pt, 모바일 360×640 최소, 스크린리더 순서, 무음 대체, 큰 글씨, 색약 대비, 점프스케어·흔들림 토글. 국문 자연어 오류·줄바꿈 테스트.
