## 퍼즐 정의
### PZ01 '없었던 집' (N2)
입력 EV01 EV02 EV03. 플레이어는 각각의 작성일을 직접 본 뒤 404호 기록이 언제 바뀌었는지 시간축에 배치. 출력 `room404_removed_after_1997=true`. 오답은 기록 재확인 UI, 즉사 없음.

### PZ02 '없었던 화재' (N3)
입력 EV06 EV07 EV08. 접수 기록과 관리소 발표의 주소·시각 비교. 출력 `fire_report_suppressed=true`. 전화만으로 정답 주지 말 것.

### PZ03 '마지막 방문자' (N4)
입력 EV09 EV11 EV12. 차량 소속+근무 기록+일정을 대조. 출력 `kang_visited_404_probable=true`. 얼굴 사진 하나로 동일인 최종 확정하지 않는다.

### PZ04 '왜 죽었는가' (N5)
입력 EV10 EV06 EV14, 추가 EV09/EV12. 살해 시점이 화재 전이었다는 점과 공개 협박 동기를 조합. 출력 `murder_before_fire_supported=true`, `motive_corruption_supported=true`.

### PZ05 '왜 지워졌는가' (N5)
입력 EV15 EV16 EV17 + PZ01~04. 누가 기록 교체를 지시했고 주민 일부가 왜 묵인했는지 연결. 출력 `coverup_evidence_complete=true`.

## 증거 무결성
- 원본/사본 구별 색상만으로 하지 말고 배지 문자로 명시.
- 출처 미상 자료는 '미검증', 검증 자료는 '확인됨'; 사건의 진실을 UI가 선제 설명하지 않음.
- 조사 일지는 사실 / 추정 / 반증을 분리. 예: '2004 화재 신고 존재'(사실), '강태준이 그날 방문했을 가능성'(추정).
- 증거 보관 결정은 접근성을 바꾸나 진엔딩을 우연히 차단하지 않도록 대체 경로 제공.
