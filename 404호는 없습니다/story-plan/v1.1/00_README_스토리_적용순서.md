## 절대 준수
- 원본 `GDD.md`, `data/visitors.json`, `data/anomalies.json`, `data/scenarios.json`, `data/endings.json`은 **백업 후 작업**. 이 패키지는 별도 설계안이며 기존 소스를 자동 변경하지 않는다.
- 사건 범죄의 진상은 **살인→증거 인멸을 위한 방화→가족 3명 사망→관계자의 기록 조작·주민 일부의 침묵→현재 유력 정치인의 재은폐**.
- 귀신·실존하는 사망자의 현재 등장·초능력은 확정된 사실이 아님. 모든 플레이 가능 핵심 단서는 현실적으로 해석 가능해야 한다.
- '방문객 출입 허가'와 '긴급 신고·구조'를 분리하고, 정답을 숨기기 위해 현실적인 안전조치를 방해하지 않는다.
- 현재 30개 엔딩 목록은 구현 완료가 아니다. 기존 E01~E06 판정 우선순위를 우선 확인하고 E07~E30은 구현 전 정의를 갱신한다.
- 이미지·동영상·성우 에셋은 **제작 사양**이며 이 패키지에 실물 미디어는 포함하지 않는다.
