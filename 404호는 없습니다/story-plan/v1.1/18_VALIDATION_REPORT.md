# 패키지 정적 검수 보고서 v1.1

## 자동 확인 통과
- 방문객 ID 100개, 중복 없음
- 이상징후 ID 100개, 중복 없음(모두 1회 연결)
- 허용 50 / 거부 50
- 1야간 고정 8개 방문객과 이상징후 ID 정합
- 기존 메인 사건 40건 보존
- 엔딩 30종, 각 4개 컷신 및 3개 이상의 대사 슬롯
- 배경 블록아웃 SVG 13개 / 캐릭터 SVG 40개
- 모든 JSON 파일 파싱 성공

## 수행하지 않은 검증
- 기존 게임 소스 및 엔진과 런타임 통합 테스트
- 원본 A001~A100 단서 문구별 완전 동일성 검사: 이번 v1.1은 A유형 수준의 장면 작성, 개별 A 단서의 세부 차이가 일부 누락돼 있음
- 실시간 보행 모션의 품질/바닥 접촉/옆면·뒷면 검수
- 최종 고퀄리티 배경 이미지 13종, 100명 개별 캐릭터, 보이스/효과음 완성
- 엔딩 gate의 실제 게임 상태식 연결과 전수 엔딩 도달 가능성 테스트
- UI 단말 실기기 / 오프라인 / 성능 검증

## 릴리스 상태
**개발 착수 패키지; 출시 준비 완료 아님.** 시나리오와 에셋은 기존 게임에서 로딩/시연된 상태가 아니다. 리소스 블록아웃은 실제 프로토타입 자산이지만 최종 아트와 동일시하지 않는다.
