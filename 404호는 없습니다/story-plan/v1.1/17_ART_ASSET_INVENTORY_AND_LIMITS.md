# 404호 v1.1 캐릭터/배경 리소스 현황

실제로 제공되는 파일: **배경 블록아웃 SVG 13종**, 역할군 보행 SVG **10명 x 4프레임 = 40파일**, 로컬 보행 검수 HTML + CSS, 별도 컨셉 보드 PNG 1장. SVG들은 아트 최종품이 아니라 **교체 가능한 프로토타입 사용 리소스**다. 구도·조명·방 구조의 실제 3D/2D 미술 검수, 정밀 발 동작, 모든 100명 인물의 외형 개별화, 게임 엔진 통합은 수행하지 않았다.

`assets/motion/preview.html`에서 브라우저로 4프레임 샘플 모션 확인 가능. 10명 역할군의 시각적 정체성은 임시 색상으로만 구분한다. 원본 게임에 자동으로 적용되지 않는다.

생성 이미지 1장의 컨셉 보드는 게임 출시 준비 완성도를 증명하지 않는다. 보드에 표시된 428개, 312장 등의 수치는 생성 이미지 속 가상 글자일 뿐 실제 산출 수량이 아니다. 게임 엔진 자산으로 사용 금지.
