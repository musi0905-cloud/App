# 0.6.1 — V001 걷기 모션

2026-09-30

- CCTV 재현에서 V001(김서윤)이 걷는 장면(`enter`, `cross`, `descend`)에만 8프레임 걷기 그림(`assets/visitor-v001-walk-8f.png`)을 사용.
- 프레임 번호는 재생 위치로 계산(`floor(cursor×8) mod 8`). 재생, 일시정지, 슬라이더 이동, 장면 이동이 모두 같은 프레임을 가리킨다.
- 프레임마다 발 위치와 몸통 중심을 측정해 맞췄다. 위아래 행의 발 위치가 약 25px 다르지만 화면에서는 튀지 않는다. 원본 그림은 수정하지 않았다.
- `descend`(오른쪽→왼쪽 이동)에서는 그림을 좌우로 뒤집는다.
- V001 이외의 방문객, 초상, 등록사진, 얼굴 확대, 서류 그림, 사건 정답, 사건 데이터는 바꾸지 않았다. 같은 기본 그림을 쓰는 V005 등도 기존 그림을 유지한다.
- 서비스워커 캐시를 `room404-v0.6.1`로 올리고 새 그림을 캐시 목록에 추가. 화면 버전 표기는 v0.6.1.
- 검사: `all-cases`에 V001 걷기 프레임과 V005 미적용 확인을 추가. 대표 프레임은 `test-artifacts/v001-walk-frames.png`.
- 걷기 그림의 얼굴은 초상과 완전히 같은 인물로 보장되지 않는다. CCTV의 작은 화면에서는 옷차림(회색 코트)이 일치해 이질감이 적었다. 실기기에서 한 번 더 확인이 필요하다.

기타
- 조사 도구 버튼의 스크린리더 이름을 내부 키(`명부` 등) 대신 화면 이름(`주민·방문 기록` 등)으로 수정.
- `tests/all-cases.mjs`가 `CHROMIUM_EXECUTABLE` 환경변수를 지원한다. Linux 이외의 OS에서는 Playwright 기본 브라우저를 쓴다.
