# v0.16.0 (2026-10-13) — 제작 에셋 연결

## 추가
- **`stage.js` 레이어 무대:** 그리는 순서는 배경 → 뒤 물체 → 접지 그림자 → 인물(조명 보정) → 앞 가림 → UI 버튼입니다. 캔버스와 변환은 고정이고, 클릭 영역은 최소 44px입니다.
- **`walk.js` 상태기계:** 입장 → 대기 → 퇴장. 클립은 한 번만 앞으로 재생하며 되감기·역재생이 없습니다. 클립이 없으면 제자리에서 불투명도만 바뀝니다.
- **`data/scene_layout.json`:** 배경 13개 각각의 파일, 연도, 카메라, 수평선, 바닥선, 바닥, 서 있는 위치, 경로, 클릭 영역, 가림, 사용처를 담았습니다.
- **`assets/bg/` 승인 배경 12장(720x1280)과 `assets/v5/figure-*` 승인 인물 전신 4장:** `scripts/build-stage-assets.py`가 만듭니다.
- **인터폰 화면:** BG02 3:4 전신 카메라로 바꿨습니다. 방문객과 기록 인물이 서 있는 위치는 PASS 정지 배치 기준을 따릅니다.
- **경비실 책상(BG01):** 모니터·기록부·전화기를 누르면 각 도구가 열립니다. 방문객을 누르면 CCTV가 열립니다.
- **배경 교체:** 야간 소개(BG13/09/04/07/12)와 엔딩 '경비실' 컷(BG01)에 승인 배경을 씁니다.
- **긴급 신고 버튼:** 판정과 분리돼 있고 저장됩니다. 판정 뒤 안내가 나오며, 판정과 엔딩에는 영향이 없습니다.
- **증거 본문 뷰어:** 카드 v03의 JSON 본문을 보여 줍니다. 확대 80~200%(버튼, 키, 핀치)를 지원합니다. 2004년 자료는 뒤에 2004년 배경을 깝니다.
- **야간 결산:** 누적 집계를 보여 줍니다.
- **`data/walk_clips.json`:** v05 `render.js` 계산을 옮겨 프레임별 발 바닥점, 몸 상자, 접지 그림자를 담았습니다. QA 뷰어 전용입니다.
- **`qa/` 내부 QA 뷰어:** 배포 밖에 있고 `npm run qa`로 엽니다.
- **`../asset_registry.json`과 `scripts/build-asset-registry.py`:** 에셋 레지스트리입니다.
- **`scripts/import-v05-frames.py`:** v05 스프라이트를 받았을 때 해시를 확인하고 아틀라스를 만듭니다.
- **테스트 추가:** `stage.test.mjs`, `world.test.mjs`, `registry.test.mjs`, `import-v05.test.mjs`, `game-ui.mjs`, `qa-ui.mjs`. 그 밖에 `screens.mjs`(화면 캡처)도 추가했습니다.

## 바뀜
- **EV06 era:** 21:31을 21:28로 고쳤습니다(카드 본문과 맞춤). 증거 데이터에 `body`, `issued_at`, `source_doc`, `card_title`, `text_status`를 추가했습니다.

- **`tests/static-server.mjs`:** 폴더 주소에서 index.html을 보여 주고 한글 경로를 해독합니다.
