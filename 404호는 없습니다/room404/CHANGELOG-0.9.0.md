# 0.9.0 — 연출·움직임·원근법 종합 다듬기

2026-09-30

v0.8.0을 처음부터 끝까지 다시 보고, 연출·캐릭터 움직임·원근법·대본 말투를 한 번에 손봤다. 사건 정답, 저장 구조, 데이터는 바꾸지 않았다.

## 캐릭터 움직임의 원근법
- 장소마다 **지평선(horizon)** 과 **먼 곳(far)** 을 정했다(`LAYOUT`). 인물의 키는 항상 발 위치로 결정된다(`heightAt`). 뒤쪽에 있으면 작고 높게, 앞으로 오면 크고 낮게 보인다.
- 카메라 쪽으로 걸어오는 움직임은 화면에서 등속이 아니다. 실제 원근(1/거리)을 따라 뒤쪽에서는 천천히, 앞에서는 빠르게 다가온다(`perspectiveY`). 경로는 화면에서 직선을 유지한다.
- 장소별 출발점: 공동현관은 현관 매트, 복도는 복도 끝, 계단은 오른쪽 위 계단, 주차장은 안쪽.
- 계단 내려오기는 오른쪽 위에서 왼쪽 아래로, 몸도 왼쪽을 향한다.
- 가로질러 걷기(`cross`)는 **이동한 거리로 걸음 프레임을 정한다.** 발이 바닥에서 미끄러지지 않는다. 깊이 방향 걷기는 시계 기준이다.
- 발밑에 **접지 그림자**를 그린다. 인물이 바닥에 서 있는 느낌이 난다. 반사된 모습에는 그림자를 그리지 않는다.
- 서 있는 인물은 3초 주기로 아주 조금 **숨을 쉰다**(세로 0.6%). 멈춘 화면에서도 살아 있는 사람으로 보인다.
- 두 사람(`double`) 장면은 걸음이 반 박자 어긋나고 숨도 반대로 쉰다.

## CCTV 연출
- 장면이 바뀔 때 0.3초짜리 **테이프 끊김**(검은 화면과 흰 줄)이 들어간다. 재생 중 장면이 넘어갈 때와 장면 번호를 누를 때. 동작 줄이기 설정에서는 꺼진다.
- HUD에 **CAM 번호**와 깜빡이는 **● REC** 표시를 넣었다. 이상 상태 글자는 천천히 밝아졌다 어두워진다.

## 판단 연출
- ‘들여보내기’를 누르면 **문이 열리는 영상**과 “문을 열었어요.”, ‘문 열지 않기’를 누르면 **닫힌 문 사진**과 “문을 열지 않았어요.”가 1초 동안 화면을 덮었다가 사라진다. 터치를 막지 않으므로 바로 다음으로 넘어갈 수 있다.
- 효과음(`sfx.js`, 파일 없이 합성): 문 여는 소리, 문이 닫힌 채 두드리는 소리, 전화 걸 때 인터폰 벨 소리 한 번. 소리 끄기 설정을 따른다.
- 판단 결과 화면의 사진이 열린 문/닫힌 문으로 바뀐다. 제목 색이 맞으면 초록, 틀리면 붉은색이다.
- 틀렸을 때 **“다음에는 이렇게 해 보세요”** 안내가 붙는다(그 사건의 확인 방법).

## 결과 화면
- 결말마다 쉬운 한 줄 설명을 넣었다(`ENDING_NOTES`). 예: 404호 — “없는 집으로 사람을 들여보냈어요. 이 밤은 여기서 끝나요.”
- 결말에 따라 제목 색이 달라진다. ‘404호’는 붉은색으로 가끔 깜빡인다. 동작 줄이기에서는 깜빡이지 않는다.

## 말투
- 결과 이미지의 “당신이라면 문을 열겠습니까?” → “당신이라면 문을 열어 줄 건가요?”
- 아래쪽 안내문을 쉬운 말로 바꿨다. “이 게임은 지어낸 이야기예요. 실제 출입 관리나 위급한 상황의 대처 방법을 알려 주는 것은 아니에요.”
- 시작 전 경비실 메모 제목을 “지금까지 알게 된 것”으로 통일했다.

## 검사
- 원근법 검사 추가: 모든 장소에서 뒤쪽이 더 작고, 다가올수록 화면 속도가 빨라지며, 앞에 도착하면 기준 크기가 된다.
- 엔진·데이터 13/13, 브라우저 9/9, 전수 100/100 통과.
- 서비스워커 `room404-v0.9.0`, `sfx.js` 추가.

## 아직 남은 것
- 받은 배경이 장소마다 한 방향뿐이라 ‘다른 방향’ 카메라는 공동현관 외에는 좌우 반전이다.
- 인물 그림은 정면·옆면 두 가지뿐이다. 비스듬히 걸어오는 장면도 옆면 그림을 쓴다.
- 효과음과 목소리 품질, 영상 재생은 실제 휴대폰에서 확인이 필요하다.
