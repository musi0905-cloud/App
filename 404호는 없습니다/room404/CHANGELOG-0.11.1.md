# 0.11.1 — 경비실 시계와 CCTV 녹화 시각 분리

2026-10-05

사용자 지적: CCTV를 볼 때 현재 시각과 영상 속 시각이 같았다.

## 바뀐 생각
- `TIMES[index]`(예 00:13)는 **방문객이 인터폰을 누른 도착 시각**이다. CCTV는 그 시각까지의 **녹화**이고, 경비원이 조사하는 동안 시간은 흘러간다.
- 경비실 시계(`#clock`)는 `nowTime()` = 도착 시각 + 1분 + 지금까지 확인한 도구 수(최대 4). 처음 00:14, CCTV·명부·전화·재확인을 할수록 00:15, 00:16….
- CCTV 제목 줄에 "00:13 도착 전까지의 녹화 · 지금은 00:14"를 적어 둘의 차이를 바로 보여 준다.
- 장면 시각 `sceneTime(frame, time, now)`: 녹화 장면은 도착 시각 기준(`offset`, 시계 7분 지연 등 그대로), **실시간 화면인 `live`·`loading` 장면만 경비실 시계(`now`)**를 쓴다(`LIVE_MODES`). 정답과 시각 단서(10분 전 영상, 같은 시각 다른 장소, 어제 날짜 등)는 바뀌지 않는다.
- 조사 결과 목록의 "실제 시각"과 "화면 시계"도 같은 규칙을 따른다.

## 장면 설명 9곳 수정
- 녹화인데 "지금 … 서 있어요"라고 적혀 있던 설명을 "현관에 도착한 사람도…", "문 앞에 온 사람도…"처럼 녹화에 맞게 고쳤다(A001, A004, A005, A039, A061, A068, A069×2, A076). 실시간 화면인 A064(live)·A068(loading)의 "지금"은 그대로다.

## 검사
- 데이터 검사에 live 장면은 경비실 시계를, 녹화 장면은 도착 시각을 쓰는지 추가. 브라우저 검사에 CCTV를 열었을 때 시계와 영상 시각이 다른지, 제목 줄에 녹화 안내가 있는지 추가.
