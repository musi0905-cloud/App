# 0.5.0 — 사건별 재현과 원본 기록

2026-09-30 (한국시간)

## 변경
- 원래 100개 사건의 판정·단서를 보존하면서 사건별 데이터 팩 추가: CCTV 40, 명부 40, 통화 20.
- 총 300개 시각/장소별 장면. 사건마다 18초 타임라인, 재생/일시정지/구간 선택/슬라이더 지원.
- 실제 촬영물/AI 생성 동영상 파일이 아닌 생성 이미지와 스프라이트를 합성한 Canvas 애니메이션. 인물의 이동·중복·반사·부재, 화면 시간/날짜/지연, 소품 제거, 장소 변경을 재현. 음성은 대화 기록으로 제공하며 음성 오디오는 없음.
- 현관/현관 보조/복도/승강기/계단/주차장/문 개폐 배경 및 모자·우산·마스크·휴대전화·상자·장갑, 이발 전 인물 이미지 사용.
- 모자·마스크 제거, 현재/과거 기록, 인원 차이, 문 열림/닫힘, 차량 유리 반사 등 비교 지원. 표현은 게임용 재현이며 실사 신체 동작 수준의 애니메이션은 아님.
- 명부: 제출 자료와 관리실 원본을 나란히 표시. 방문 주장, 변경/취소/승인 식별값, 자료 출처 제공.
- 통화: 발신 경로, 연결 상태, 경비원 질문·응답·관찰 기록을 순서대로 표시.
- 원본 단서와 무관했던 무작위 방문객 직업·주장을 해당 사건에 맞게 연결.
- 조회 전 단서와 최종 확인 결과는 숨김. 기존 0.2.0 엔진 저장 구조 유지, UI/캐시 버전만 0.5.0.

## 검증 범위
- 엔진 및 시나리오 데이터 검사 11개.
- Chromium 자동 UI 검사: 100건 전체, 300개 장면 선택, 명부/통화/마지막 확인/정답 판정, 조회 전 비공개, 모바일 폭 넘침 및 JS 오류 검사.
- 기존 8건 근무/저장 복원/이미지 내보내기/로컬 오프라인/데이터 오류 복구 회귀 검사 9개.
- 최종 통과 여부와 시각은 test-artifacts의 JSON 참고. 일부 대표 장면만 시각적으로 직접 검토했으며 300개 장면 모두를 사람이 육안 검수한 것은 아님.
- 실제 iPhone 기기와 공개 배포 인증까지 포함한 오프라인 실행은 미검증.

## 코드 구조
- dist/data/scenarios.json: 100개 사건의 장면/자료/통화 정의
- dist/replay.js: 재생 가능한 시각화
- dist/game.js: 조회·판정·기록 연결
- SCENARIO_COVERAGE.json: 사건별 대응 명세
- tests/all-cases.mjs: 100건 자동 전수 UI 검사
