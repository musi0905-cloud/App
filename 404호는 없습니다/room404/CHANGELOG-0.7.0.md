# 0.7.0 — 쉬운 대사, 전화 목소리, 넘기는 기록부

2026-09-30

## 모든 대사를 쉬운 말로 다시 씀
- 100개 사건의 화면 문구를 모두 다시 썼다. 방문객의 말, CCTV 장면 설명, 기록부, 통화, "지금 알게 된 것", "다음에는 이것을 확인하세요", 확인 결과가 대상이다.
- 기준은 해요체, 한 문장에 한 가지 사실, 되도록 30자 안팎이다. "승인·대조·원본·세대·신원·진위" 같은 어려운 말은 쓰지 않는다. 자세한 기준은 `docs/WRITING_GUIDE.md`에 있다.
- 틀린 말을 고쳤다(예: "돌려보냄된", "보여 줌하고"). 영어 약호(R-0000, D-202 등)는 쉬운 말로 풀었다.
- 조사 전에 답이 드러나지 않게 했다. 방문객의 말과 첫 통화, CCTV 설명에 결론이 보이지 않는지 따로 검토해 고쳤다(76곳).
- 정답(`safe`), 핵심 도구(`channel`), 원래 단서(`clue`, `verification`), 장면 동작은 바꾸지 않았다.
- 화면 문구도 쉽게 바꿨다. 예: "판단이 맞았습니다" → "잘 판단했어요. 맞았어요", "정답 8건 · 위험 허용" → "8명 중 8명 맞힘 · 위험한 사람을 들여보냄", "오프라인 준비 완료" → "인터넷 없이도 할 수 있어요".
- CCTV 장소 이름을 바꿨다. "승강기"는 "엘리베이터", "계단실"은 "계단", "현관 보조 카메라"는 "현관 옆 카메라".

## 전화: 실제 목소리로 듣기
- 각 사건에 실제 통화 대본을 넣었다. 첫 통화(`call.dialogue`)는 3~5줄, 한 번 더 확인하는 통화(`call.verifyDialogue`)는 2~4줄이다.
- '전화 걸기'를 누르면 휴대폰에 들어 있는 한국어 음성으로 통화를 읽어 준다(`voice.js`). 지금 말하는 줄은 화면에 표시된다.
- 경비원, 주민, 관리실, 모르는 사람 등은 목소리 높이와 빠르기를 다르게 했다.
- '통화 다시 듣기', '멈추기', '소리 켜짐/꺼짐' 버튼이 있다. 소리 설정은 기기에 저장된다(`404_sound`).
- 웹에서는 speechSynthesis를 쓴다. 앱(Capacitor)에서는 TextToSpeech 플러그인을 설치하면 그것을 쓴다. 음성이 없는 기기에서는 글로 읽으라는 안내가 나온다.

## 기록부: 한 장씩 넘기기
- '기록부 펼치기'를 누르면 4장짜리 관리실 기록부가 열린다.
  1. 오늘 밤 방문 기록 (앞서 온 사람 3명과 지금 온 사람)
  2. 이 사람이 말하거나 보여 준 것
  3. 관리실에 적혀 있는 것
  4. 두 기록을 나란히 보기
- 버튼, 옆으로 밀기, 키보드 화살표로 넘긴다. 넘길 때 종이가 넘어가는 효과가 있고, 동작 줄이기 설정을 켜 두면 효과가 꺼진다.

## 기타
- 사건 문구의 `{name}`, `{unit}`이 어느 칸에서도 그대로 보이지 않도록 사건 전체에 한 번에 채운다(`fillDeep`).
- 서비스워커 캐시 `room404-v0.7.0`. `voice.js`를 캐시 목록에 추가했다.
- 검사를 추가했다: 기록부 넘기기(버튼, 밀기, 키보드), 통화 음성(줄 수, ko-KR, 사람마다 다른 목소리, 소리 끄기), 모든 사건에서 `{name}`/`{unit}`이 남지 않는지.

## CCTV 여러 각도 보기
- 사용자가 새 각도 배경 그림을 만드는 중이다. 그림이 준비되면 그에 맞춰 넣는다. 필요한 그림 규격은 `docs/CCTV_ANGLE_IMAGE_SPEC.md`에 있다.
