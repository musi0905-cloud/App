# v0.19.0 (2026-10-17) — 확보한 그림·애니메이션의 게임 적용

## 바뀐 것

- 방문객 그림을 사건(방문객+시나리오)마다 정합니다(`figures.js figureFor`, `data/visitor_figures.json`).
  - 인터폰과 CCTV가 같은 판정을 쓰므로 두 화면의 인물이 항상 같습니다.
  - 역할 그림 8종이 19개 사건에 나옵니다. 나머지 81개 사건은 기존 외형을 두 화면에 똑같이 씁니다.
- NPC06 v10r5가 인터폰에서 입장 → 정지 전환 → 대기 → 회전 → 퇴장 시작 → 퇴장을 재생합니다(4개 사건).
  - 판정은 즉시 저장되고, 방문객이 돌아서 나간 뒤 결과가 나옵니다. "결과 바로 보기" 버튼이 있습니다.
  - 시각 판정은 REVISE입니다. 사용자 예외 승인으로만 쓰며, 정확한 판·해시를 대조합니다.
- CCTV 가로지르기 장면에서 역할 그림의 측면 걷기(v06 side PASS, NPC06·NPC07·NPC09)를 그립니다.
  - 그림 방향 그대로 그리고, 좌우 반전하지 않습니다.
- 모션 감소 설정: 대기 정지 프레임만 보여 주고, 판정하면 바로 결과로 갑니다.
- 로드 실패나 해시 불일치: 정지 그림으로 대체하고 콘솔에 기록합니다.
- 오프라인 캐시 `room404-v0.19.0`: 역할 그림 10장, NPC06 페이지 7장, 측면 걷기 3장을 추가했습니다.
  - 검토 영상, ZIP, 원본 프레임은 넣지 않았습니다.

## 바뀌지 않은 것

- 사건 정답, 엔딩, 저장 형식(기존 저장 그대로 이어짐), 이름·날짜, 긴급 신고 분리
- 전역 REVISE 차단(`stage.js clipUsable`)
