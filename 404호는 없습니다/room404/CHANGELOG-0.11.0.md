# 0.11.0 — 이미지 v3 묶음 C·D·E 적용 (새 방문객 4명, 소품 8개, 화면 3장)

2026-10-05

Drive `이미지_v3`에 새로 올라온 23개 파일을 받아 `visual-v3/`에 원본 보관(`asset-manifest.json`의 SHA-256 전부 일치)하고 WebP로 줄여 적용했다. 기존 01~04번 파일은 바뀌지 않았다.

## C. 새 방문객 4명 (visitor-05 ~ 08)
- 05 택배 기사(모자, 상자), 06 시설 점검(작업복), 07 돌봄 방문(노년 여성), 08 지인(젊은 여성). 각각 서기·다가오기·동작 시트.
- **역할로 그림을 고른다**(`ROLE_LOOK`, `lookFor()`): 택배 기사→05, 시설 점검→06, 돌봄 방문→07, 지인→08. 나머지 역할은 전처럼 번호 순환(01~04). 시나리오가 "방문객이 주장하는 역할"(`v.role`)을 바꿔도 그림은 실제 기록의 역할(`v.baseRole`)을 따른다.
- 05~08번에는 옆모습·뒷모습 걷기 시트가 없어 `side`/`away`는 앞모습 시트로 대신한다(가로지르기·반대편 카메라 장면). 다음 묶음에서 받으면 자동으로 쓴다.
- **서 있는 그림 통일**: `assets/visitors.png`(4칸, 384×1024) 대신 사람마다 `visitor-0N-stand.webp`(384×512, 발 496·머리 26)를 쓴다. 01~04는 동작 시트의 '기다리기' 칸을 잘라 만들었다. 인터폰 상반신, 초상, 등록 사진, 얼굴 확대가 모두 이 그림을 쓴다. `visitors-before-haircut.png`는 더 쓰지 않고, '예전 사진' 장면은 같은 그림을 세피아로 바래게 하고 머리선을 가려 표현한다.

## D. 소품 8개
- bag(비닐봉지), cap-reflective(반사띠 모자), card(목걸이 카드), flowers(꽃다발), keys(열쇠), medicine(약 봉지), paper(종이), toolbox(공구함).
- 장면에 단서 소품(`scene.prop`)이 없을 때만 **역할별 기본 소품**을 든다(`ROLE_PROP`: 음식 배달→bag, 시설 점검→toolbox, 돌봄 방문→medicine, 지인→flowers, 공공 업무→paper, 귀가 주민→keys, 차량 동승→card). 단서 소품과 '없어진 소품' 장면은 그대로라 정답에 영향이 없다.

## E. 화면 3장
- `lobby-door-inside`: 인터폰 모니터 배경(공동현관 유리문 정면). 전에는 CCTV 공동현관 배경을 썼다.
- `guard-monitors`: 판단 결과 화면 배경(경비실 모니터 4대).
- `ending-404`: '404호' 결말의 결과 화면 배경(어두운 복도 끝의 문). 다른 결말은 새벽 영상 그대로.
