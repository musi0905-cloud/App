# 0.10.1 — 인물 크기를 배경에 맞춤

2026-09-30

- 캡처를 보면 인물이 배경의 문·차에 비해 절반 정도로 작았다. 장소마다 사진 속 기준 물체(문 2.1m, 차)를 재서 **같은 깊이에서 사람이 문의 약 80%** 가 되도록 `LAYOUT`의 키와 지평선을 다시 정했다.
  - 예: 공동현관 매트 앞 인물 165px → 210px, 현관문 앞 인물 300px → 450px, 복도 근처 인물 181px → 300px.
  - 복도·엘리베이터처럼 카메라 바로 아래가 지나치게 커지는 곳은 서 있는 자리를 조금 뒤(y 587→500 등)로 옮겼다.
- **걷기 영상(13~16)과 이상 장면 영상(17~22)은 CCTV에서 빼고** 모든 인물을 캔버스로 그린다. 영상 속 인물은 크기가 고정되어(작게) 새 기준과 맞지 않기 때문이다. 이 영상들은 처음 안내의 예시로만 쓴다. 장소별 모니터 영상(03~08)과 문 영상은 그대로 배경으로 쓴다.
- 가까이 보기 배율을 2.2배에서 1.8배로 낮췄다(인물이 커졌으므로).
- 검사: 엔진·데이터 14/14, 브라우저 9/9, 전수 100/100 통과.
