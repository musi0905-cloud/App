# 404호는 없습니다 — 쉬운 설명을 위한 참고 조사

검토일: 2026-09-30 (한국시간)

## 읽은 자료와 적용한 점

1. Papers, Please 공식 소개/프레스킷
   https://papersplea.se/presskit/
   여행자가 준 자료와 확인 도구로 입장 여부를 판단하는 게임이라고 설명한다. 이번 게임에서는 이 구조를 참고해, '방문객이 보여 준 것'과 '관리실에 적힌 것'을 나란히 제시했다. 공식 소개를 읽은 비교이며, 이번 조사에서 게임 전체를 직접 플레이한 분석은 아니다.

2. Game Accessibility Guidelines — Use simple clear language
   https://gameaccessibilityguidelines.com/use-simple-clear-language/
   불필요한 길이와 복잡함을 줄이고, 해야 할 행동을 직접 안내하는 방식을 권한다. 이를 참고해 각 사건을 '지금 알게 된 것'과 '다음에 확인할 것'으로 나눴다. 이는 출처의 권고를 이 게임에 적용한 설계 판단이다.

3. GOV.UK — Use clear language
   https://guidance.publishing.service.gov.uk/writing-to-gov-uk-standards/writing-guidelines/clear-language/
   쉬운 단어, 구체적인 동작, 짧은 문장, 필요한 전문 용어의 설명을 권한다. 한국어에서는 '신원', '원본 대조', '독립 재확인', '출입 승인 미확정'처럼 추상적인 표현을 풀어 썼다. 영어권 지침의 원칙을 한국어에 적용했으며, 한국어 이용자 대상 이해도 실험을 실시한 것은 아니다.

| 출입 허용 / 출입 거부 | 들여보내기 / 문 열지 않기 |

## 이번 버전의 작성 기준

- 한 문장에 한 가지 사실을 담는다.
- 누가 무엇을 했는지 밝힌다.
- 사실과 다음 행동을 나누고, 버튼은 누르면 하는 일로 적는다.
- 같은 행동에는 같은 이름을 사용한다.
- 확인 전에는 정답이나 마지막 확인 결과를 보여 주지 않는다.
- 이전 버전의 사건, 판정, 장면을 유지한다. 원래 단서는 데이터에 보존하고 표시용 쉬운 설명을 별도로 둔다.
- 단어만 바꾸며 생긴 조사·문법 오류는 별도로 점검한다.

## 저장 및 검증

100개 사건에 `plain.what`, `plain.check`, `plain.confirmed`, `plain.decision`을 추가했다. 장면과 정답 값은 그대로 유지했다. 엔진/사건 정의 검사 11개 및 기존 모바일 화면·근무·저장·오프라인 회귀 검사를 실행했다. 사용자의 실제 이해도는 직접 플레이 피드백으로 추가 확인해야 한다.
