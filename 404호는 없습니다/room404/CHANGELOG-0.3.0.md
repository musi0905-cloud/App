# 0.3.0 — 조사 화면 전환

2026-09-29

- CCTV, 명부, 확인 통화, 독립 재확인을 각각 별도의 작업 화면으로 분리.
- 버튼을 열기만 하면 조사로 처리되던 흐름을 실제 조회/통화 버튼을 눌러 기록하는 흐름으로 변경.
- CCTV → 명부 → 통화 → 독립 재확인 → 경비실 판단의 순차 이동 지원. 도구를 자유롭게 선택하는 기존 방식도 유지.
- 조회한 자료 재열람, Escape/돌아가기, 조사 진행 표시 지원.
- CCTV 배경은 생성된 정지 이미지이며 인물/이상현상을 움직이는 영상으로 재현하지 않음. 사건별 단서는 관찰 기록으로 표시.
- 기존 0.2.0 저장 데이터를 유지하기 위해 엔진 데이터 버전은 유지. UI 및 캐시 버전 0.3.0.

## 검증
- 엔진 테스트 7/7 통과.
- Chromium 모바일 크기 브라우저 시나리오 9/9 통과: 화면 전환, 조회 후 기록, 순차 조사, 재열람, 320~1280px 폭, 새로고침 저장, 8건 판정/엔딩, PNG 저장, 로컬 오프라인 재실행, 저장 손상 복구, 자료 요청 실패/재시도, JS 오류 없음.
- 실제 iPhone 및 배포 주소의 인증을 포함한 오프라인 실행은 검증하지 않음.
- 테스트 결과 JSON과 화면 캡처를 백업 ZIP에 포함.
