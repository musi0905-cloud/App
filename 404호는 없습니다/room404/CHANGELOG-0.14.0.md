# 0.14.0 — 5야간 이야기와 엔딩 E07~E30 조건 연결

2026-10-08

Drive `스토리_개발기획_v1.3_엔딩시뮬레이션`의 `CLAUDE_CODE_IMPLEMENT.md`를 먼저 읽고, `ending_gates_30_simulated.json`과 `simulation_witnesses_30.json`을 기준으로 엔딩 조건을 실제 엔진에 넣었다. v1.2 `S2-S5_기획결정`(저장·야간 흐름, 40슬롯)도 함께 적용했다. 검증 결과와 남은 모순은 `docs/ENDING_VERIFICATION_REPORT.md`.

- 첫 근무가 1야간이 되고, 2~5야간이 이어진다. 각 야간 8건의 방문객 ID·이상징후·시각은 v1.2 40슬롯 그대로다. 1야간은 기존 고정 8건과 같고, 결말 E01~E06은 기존 엔진 판정을 그대로 쓴다.
- 2~5야간은 판정 뒤 '기록을 들고 온 사람' 카드가 나온다. 독립 자료를 대조해야 자료(EV)를 받고, 장면마다 처리 방법을 고른다. 판정 화면에는 기록·증거·엔딩이 나오지 않는다.
- 야간이 끝나면 기록 보관함: 자료 교차 확인(입수≠확인), 기록 대조 퍼즐 PZ01~PZ05, 근무 기록에서 '이 기록으로 마무리'(E07~E27), 놓친 자료 복구. 5야간 뒤 최종 증거보드에서 E28·E29·E30을 고른다. E30은 조건이 모자라면 제출 버튼이 꺼지고 무엇이 모자란지 알려 준다.
- 저장: 이야기는 `404_story_v3`. 옛 첫 근무 저장(`404_active_v2`)은 1야간 이야기로 옮기고 원본은 `404_active_v2_backup`에 둔다. 읽을 수 없는 저장은 따로 보관하고 새로 시작한다. 엔진 `VERSION` 0.2.0 그대로.
