# 404호는 없습니다 — 이미지·모션 v2

2026-09-30 제작. 원본 v0.6.0의 화면 구조를 확인해 만든 에셋 패키지입니다. 모든 항목은 개별 파일이며 ZIP이 아닙니다. 이 폴더를 저장한 것과 실제 게임에 적용·배포한 것은 다릅니다. 이번 결과물은 에셋과 검수용 플레이어이며, 운영 게임은 수정하지 않았습니다.

## 구성

- `images/`: 배경 PNG 13개, 캐릭터 걷기 원본 시트 4개, 소품 원본 시트 1개.
- `images/visitor-01` ~ `visitor-04`: 캐릭터별 8프레임, 총 32개 투명 PNG. 공통 384×512 캔버스와 발 위치로 정렬했습니다.
- `images/props/`: 모자, 접힌 우산, 마스크, 휴대전화, 택배 상자, 장갑 등 6개 투명 PNG.
- `motion/`: 23개 독립 MP4. 960×640, 24fps, 6초, H.264, 무음. 예시 시각·문구는 영상에 넣지 않았습니다.
- `previews/`: 각 모션 2.5초 지점의 JPEG 미리보기.
- `runtime/scene-player.mjs`: 배경/프레임을 합성하는 결정론적 Canvas 렌더러와 브라우저 플레이어.
- `runtime/sprite-manifest.json`, `motion-manifest.json`: 프레임과 모션 속성.
- `preview.html`: 장면별 재생·정지·탐색 검수 화면.
- `docs/`: 레퍼런스·화면 대응·제작 방식·검증 결과.

## 미리보기

폴더 구조를 유지해 내려받은 후 이 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/preview.html`을 엽니다. Google Drive 미리보기로도 개별 PNG와 MP4를 확인할 수 있습니다. HTML을 Drive 안에서 실행할 수 있다는 뜻은 아닙니다.

모션 감소 설정에서는 자동 재생을 하지 않습니다. 브라우저 탭이 숨겨지면 재생이 멈춥니다. 시작 화면과 결과 화면은 각각 야간 외관과 같은 건물의 새벽 외관입니다.

## 게임에 적용할 때

1. 현재 배포본과 분리한 작업 브랜치/복사본에서 시작합니다.
2. `images/`를 `dist/assets/visual-v2/` 아래로 복사하거나, manifest의 상대 경로를 실제 경로로 변경합니다.
3. CCTV 장소별 배경은 원본 `dist/replay.js`의 `LOCATIONS`와 대응합니다. 기존 `apartment-scenes.png`, `detail-scenes.png`를 3분할하는 부분을 장소별 PNG 로딩으로 바꿉니다. 새 PNG를 기존 아틀라스 파일명으로 덮어쓰면 잘못 잘립니다.
4. 캐릭터 프레임은 `sprite-manifest.json`을 기준으로 읽습니다. 기존 `(Number(visitor.id.slice(1))-1)%4` 외형 매핑을 유지할 때 1~4 에셋을 선택합니다. 100명의 개별 인물 외형을 새로 만든 패키지가 아닙니다.
5. `scene-player.mjs`는 에셋 검수·환경 연출용입니다. 기존 `mountReplay`와 인자가 동일한 교체 파일이 아닙니다. 100개 사건의 시각, 인원, 증거, 정답 로직은 기존 데이터를 유지해 별도로 연결해야 합니다.
6. `door-closed.png`와 `door-open.png`는 상태별 정지 배경입니다. `09-door-comparison.mp4`는 상태 비교용 전환이며, 실제 경첩을 따라 문이 물리적으로 회전하는 시뮬레이션이 아닙니다.
7. 명부의 이름·호수·통화 내용·날짜·정답은 HTML/Canvas 텍스트로 올립니다. 이미지에 쓰여 있는 작은 장식 형태를 실제 데이터로 읽지 않습니다.
8. `reducedMotion`이 켜지면 정지 상태를 제공합니다. 모바일에서는 모든 MP4를 선로딩하지 말고 현재 화면 영상만 로딩합니다. PNG 원본은 약 49.7 MB이므로 실제 배포 전 화면 크기별 WebP 변환·지연 로딩이 필요합니다.

## 범위와 한계

- 배경/캐릭터/소품은 AI 생성 이미지입니다. 모션은 해당 이미지의 프레임 재생과 Canvas 합성입니다. 실사 촬영이나 3D 모션 캡처, Higgsfield 생성 영상이 아닙니다.
- Higgsfield 생성은 계정 플랜 제한으로 거절되어 내장 이미지 생성으로 전환했습니다. 결제/플랜 변경은 하지 않았습니다.
- 4종 캐릭터의 걷기 프레임에는 얼굴·옷 주름·걸음 높이의 미세 변화가 있습니다. 8프레임의 제한된 애니메이션이며 방향별 3D 리깅 자산은 아닙니다.
- 세부 제스처(고개 회전·노크·손 흔들기 등)와 모든 100개 사건/300구간의 전용 영상까지 완성한 것은 아닙니다. 기존 사건 재현을 유지하면서 새 배경·걷기 프레임·환경 효과를 연결할 자료입니다.
- 적외선/반사/그림자/신호 끊김은 게임용 시각 효과이며 실제 카메라의 광학·센서 시뮬레이션은 아닙니다.
- 이미지별 공간은 일관된 미술 방향으로 제작됐지만, 같은 3D 모델에서 렌더링한 정밀 다중 시점 자료는 아닙니다.

## 재생성

`runtime/render-movies.cjs`는 Node.js의 `@napi-rs/canvas`와 로컬 `ffmpeg`로 MP4를 렌더링합니다. 패키지 루트에서 `node runtime/render-movies.cjs`를 실행합니다. 재생성은 기존 motion 및 preview 파일을 덮어쓰므로 별도 사본에서 실행하세요. 원본 그림을 새로 생성하는 스크립트는 아닙니다.
