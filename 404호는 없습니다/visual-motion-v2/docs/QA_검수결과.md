# 에셋 검수 결과

- PNG 56개: 파일 디코딩과 크기 확인. 배경 13개, 원본 캐릭터 시트 4개, 소품 시트 1개, 정렬된 캐릭터 프레임 32개, 소품 개별 파일 6개.
- 캐릭터 32프레임: RGBA/384×512 확인. 투명 영역과 발 기준선을 확인하고 공통 높이로 정렬.
- MP4 23개: ffprobe 메타데이터 확인 및 ffmpeg 전체 디코딩 성공. H.264/960×640/24fps/144프레임/6초/무음.
- 출력 도중 손상된 CCTV 파일 3개는 재렌더링 후 전체 디코딩을 다시 통과.
- 배경 13종과 생성 시트를 생성 결과에서 확인. 대표 합성 장면 및 23종 모션의 2.5초 미리보기 모음을 눈으로 확인.
- JS 렌더러와 영상 생성 코드의 구문 검사 통과. 같은 scene-player 모듈로 미리보기 이미지와 MP4를 생성.
- 현재 환경에 Chromium 실행 파일이 없어 HTML의 실제 브라우저 조작 검사는 수행하지 않음. iPhone 실기기, 원본 게임의 100개 사건 회귀 검사는 수행하지 않음.

## 확인된 시각적 한계

캐릭터는 생성형 8프레임으로 얼굴·옷 주름·걸음 높이가 미세하게 변할 수 있습니다. 3D 리깅 기반의 매끄러운 360도 캐릭터가 아닙니다. 배경과 캐릭터가 서로 다른 시점에서 생성돼 실제 게임에 연결할 때 장소별 크기·색감·바닥 접점을 다시 조정하는 편이 좋습니다. 고개 회전, 노크, 손 흔들기 등 별도 제스처는 이번 4종 걷기 시트에 포함되지 않았습니다.

`09-door-comparison`은 열린/닫힌 정지 상태 사이의 비교 전환이며 물리적 문 회전 영상이 아닙니다. CCTV 시계·사건 문구는 MP4에 고정하지 않았습니다. preview.html에 표시되는 시각은 검수용 예시입니다.
